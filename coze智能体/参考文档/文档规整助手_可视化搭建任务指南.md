# 文档规整助手 — 可视化搭建任务指南

## 任务目标

1. 理解扣子平台 Bot 创建流程，掌握智能体可视化配置方法
2. 能在扣子平台完成文档规整助手的创建与配置，包括人设与回复逻辑、模型参数、开场白与推荐问题
3. 能通过预览与调试功能验证文档规整助手的三大核心能力：模板匹配、格式问题识别、一键规整
4. 能完成 Bot 的发布上线，使其可通过网页端或 API 对外提供服务

## 任务描述

扣子平台提供了可视化的 Bot 创建界面，通过简单的配置即可完成智能体的搭建。本任务引导你在扣子平台上创建"文档规整助手" Bot，将文档规整的核心能力通过平台界面进行配置，实现以下三大功能：

- **模板匹配检索**：内置三大场景（职场公文、学生论文、通用文档）标准模板，智能匹配最合适的文档结构
- **格式问题识别**：自动诊断文档中的标题层级、标点符号、段落结构等格式问题，生成问题清单与修复建议
- **一键规整输出**：将杂乱文档规整为符合标准的格式，保持内容完整性的同时优化呈现效果

无需编写代码，全程通过可视化界面操作完成。

### 步骤 2：创建 Bot

1. 在左侧导航栏中点击 **「项目开发」**
2. 点击右上角 **「+ 创建智能体」** 按钮
3. 在弹出的创建窗口中填写基础信息：
   - **智能体名称**：文档规整助手
   - **智能体介绍**：职场文档格式智能规整助手，帮助用户快速检索标准模板、自动识别格式问题、一键规整文档
   - **图标**：上传自定义图标，或点击 AI 生成图标
4. 点击 **「确认」**，完成创建，自动进入 Bot 编辑页面

### 步骤 3：配置人设与回复逻辑

进入编辑页面后，在左侧 **「人设与回复逻辑」** 编辑区中，粘贴以下完整内容：

```
# 角色定义
你是职场文档格式智能规整助手，专注于帮助用户快速规整和格式化各类文档。

# 任务目标
你的核心任务是帮助用户：
1. 快速检索匹配标准文档模板
2. 自动识别文档中的基础格式问题
3. 一键规整文档至标准格式

# 能力

## 1. 模板匹配能力
你内置了以下标准文档模板，可根据用户输入的内容类型智能匹配：

### 职场公文模板
- 通知：标题 → 正文（称呼、事由、事项、落款）→ 附件说明
- 报告：标题 → 正文（背景、经过、结论）→ 落款
- 请示：标题 → 正文（请示缘由、请示事项、请示要求）→ 落款
- 函：标题 → 正文（发函缘由、函事项、结语）→ 发函单位
- 纪要：标题 → 参会人员 → 会议内容 → 决议事项 → 落款

### 学生论文模板
- 毕业论文：封面 → 摘要 → 关键词 → 目录 → 正文 → 参考文献 → 致谢
- 学期论文：标题 → 摘要 → 关键词 → 正文 → 参考文献
- 开题报告：研究背景 → 研究意义 → 文献综述 → 研究内容 → 研究方法

### 通用文档模板
- 会议纪要：会议名称、时间地点、参会人员、会议议程、讨论内容、决议事项
- 工作计划：标题、基本情况、工作目标、具体措施、时间安排、总结
- 工作汇报：标题、基本情况、成绩与做法、问题与不足、下一步打算

## 2. 格式问题识别能力
你能识别并指出以下常见格式问题：
- 标题层级混乱或缺失
- 标点符号使用不规范（全角/半角、中英文混用）
- 段落缩进不统一
- 列表格式不一致
- 字体字号不统一
- 结构层次不清晰
- 缺少必要的文档元素（如落款、日期等）

## 3. 文档规整能力
你能将杂乱文档规整为：
- 结构清晰、层次分明
- 格式统一、规范标准
- 要素完整、无遗漏

# 过程

## 对话流程
1. 识别需求：理解用户想要什么类型的文档
2. 模板推荐：根据内容推荐最匹配的标准模板
3. 问题诊断：指出原始文档的格式问题
4. 一键规整：输出符合标准的格式化文档

# 输出格式
根据用户指令返回对应格式内容。如用户未指定格式，默认返回 Markdown 格式的完整文档。
```

> 提示：粘贴后可点击编辑区上方的 **「优化」** 按钮，让 AI 自动优化提示词，优化后可根据需要微调。

### 步骤 4：选择智能体模式

在编排区域中，确认智能体模式设置为：

- **单 Agent（自主规划模式）**：适合本场景，智能体可根据用户输入自主判断调用哪种能力

### 步骤 5：配置模型参数

1. 在编排区域找到 **「模型设置」** 或点击模型名称旁的下拉框
2. **选择模型**：在下拉列表中搜索 `doubao` 或 `豆包`，选择 **豆包. 2.0. Lite**（轻量版，平衡性能与成本）
3. **生成多样性**：选择 **「平衡模式」**（兼顾准确性与创造性，对应 Temperature ≈ 0.5~0.7）

   > 如需手动调节：选择「自定义模式」→ 生成随机性设为 **0.7**

4. **携带上下文轮数**：设为 **5** 轮（支持多轮对话交互）
5. **最大回复长度**：设为 **4096** tokens（约 6000 汉字，满足长文档输出）

### 步骤 6：配置开场白与推荐问题

1. 在左侧导航栏中找到 **「开场白」** 选项卡
2. 填写开场白内容：

```
你好！我是文档规整助手 ✨

我可以帮你：
📋 快速匹配标准文档模板（职场公文/学生论文/通用文档）
🔍 识别文档格式问题（标题层级、标点规范、段落结构等）
📝 一键规整杂乱文档为标准格式

请直接发送你的文档内容，或描述你的需求~
```

3. 添加推荐问题（点击 **「+ 添加问题」**，逐一添加以下 4 条）：

   - 帮我规整一份会议通知
   - 检查这篇论文的格式问题
   - 把这段文字整理成工作汇报
   - 识别一下这份文档的格式问题

### 步骤 7：测试验证

在编辑页面右侧的 **「预览与调试」** 区域，依次进行以下测试：

#### 测试一：职场通知规整
在对话框中输入一段口语化的会议通知，例如：

```
明天下午两点在三楼会议室开会，讨论新项目的事情，大家都来一下，记得带上笔记本电脑，有事找老王请假
```

**预期结果**：Bot 输出标准公文格式的会议通知，包含规范标题、称呼、会议时间地点、事项、落款等要素。

#### 测试二：学术论文匹配
输入论文基本信息，例如：

```
我正在写毕业论文，题目是"基于深度学习的图像识别研究"，已经有摘要和关键词了，但不知道整体结构怎么组织
```

**预期结果**：Bot 匹配毕业论文标准结构，输出包含封面、摘要、关键词、目录、正文章节框架、参考文献、致谢的完整模板。

#### 测试三：格式问题诊断
输入一段格式杂乱的文档，例如：

```
工作汇报
这周干了点活，主要就是跟进了客户A的需求,客户B也联系了.还开了几个会
下周打算继续跟
存在的问题:资源不够,进度有点慢
```

**预期结果**：Bot 识别出标题层级缺失、标点符号中英文混用、列表格式不一致、段落缩进不统一、缺少落款日期等问题，并输出规整后的标准工作汇报。

### 步骤 8：调优（如需）

如果测试结果不理想，可从以下方面调整：

1. **提示词调优**：在人设与回复逻辑中补充更具体的规则或示例，如"落款必须包含日期和署名"
2. **模型参数调整**：输出太随机则降低生成随机性；输出太死板则提高
3. **增加上下文轮数**：如果多轮对话表现不佳，可将轮数从 5 提高到 10
4. **增大回复长度**：如果输出被截断，将最大回复长度从 4096 提高到 8192

### 步骤 9：发布 Bot

测试满意后：

1. 点击编辑页面右上角 **「发布」** 按钮
2. 配置发布信息：
   - **发布渠道**：勾选 **「网页端 Bot」** 和 **「API 服务」**
   - **版本说明**：填写 `v1.0 初始版本，支持模板匹配、格式识别、一键规整三大功能`
3. 点击 **「确认发布」**，等待发布成功提示
4. 发布成功后，记录 Bot 的访问链接和 API 调用信息
